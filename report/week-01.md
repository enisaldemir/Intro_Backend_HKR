I started setting up the framework and it's connection to Github and the remote repository. I will use both Mac and Windows through the development process. Thus, I believe Github will help me a lot in keeping the development process smooth. 

I already had some experience with Git, but using two remote repositories was new to me. I learned the difference between origin and upstream, and how to get updates from the teacher's repository. I also had some problems with Node.js versions, especially on Windows. I solved them by using NVM, which also allows me to use different Node.js versions for different projects.

In exercise 1-20, I worked with a simple to-do list application. I learned how to split the code into different files using import and export. I also practiced using return instead of console.log(), handling errors, and converting JavaScript data into JSON. The automated tests were familiar to me because of my testing background, although using Node.js's built-in test tools was new.

Exercise 1-30 was more difficult for me. I created a simple web server using Node.js, but at first I was confused about requests, responses and why we needed two separate files. Running the server and sending requests with curl helped me understand these concepts better. I also learned how the server returns different responses depending on the URL, including JSON and HTTP status codes such as 200 and 404.

The most important thing I learned this week was how separating code into different parts makes it easier to understand, reuse and test. I still need more practice with backend development, especially HTTP and server-side programming, but I feel more comfortable with the basic concepts now.
